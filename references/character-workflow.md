# 角色与场景

## 选定参考

无角色输入时用 `assets/default-style-reference.png` 作为编辑插画风格参考：概括形体、清楚轮廓、黑白与有限平涂、任务互动。该图提供画风依据，不要求复用其人物身份或办公布景；一旦本项目选定并确认了角色身份，后续沿用该身份。

用户 IP 保留身份标志、比例、原媒介和固定五官；例如空白圆眼不能为做表情擅自增加瞳孔。真人保留可辨身份、年龄与衣着，不默认卡通化。角色图同时说明线条/材质、光影和可搭配的道具语言；环境推断不能写成人物事实。

在项目里留存选定的风格与身份参考、用途和用户确认依据。每次生成前读取，并实际传入工具的参考图参数；同一张图可同时承担身份和风格。保持同一参考，不轮换各页结果当母图。只有需要侧背面等角度时才补多视图。

## 任务与构图

先说清人物正在完成什么任务，以及如何帮助解释页面内容，再选全身、半身、近景、局部或多人场景。参考锁定身份和画风，不继承其中的办公室、桌面、家具或机位；只有本页任务确实需要时才使用这些元素。

生成插画内部以角色为第一视觉主体：先设计姿态、表情、视线和动作，再决定最少需要哪些道具。能通过角色自身动作讲清的，不额外搭建场景。书桌仅在任务依赖桌面操作时使用；“讲 AI、工作、创作、分析”本身不构成使用书桌的理由。此规则限定插画内部主次，不要求角色压过整页的原生标题、图表或真实截图。

允许适当夸张动作幅度、身体倾斜、表情和角色自身的透视，以强化本页情绪或结论；保持身份标志、固有身体比例和原媒介；透视允许近大远小，不借夸张改变头身比或固定五官，真人不因此变成卡通。不要靠放大前景物件制造冲击力。道具与家具从属于角色，控制其体量、对比、饱和度和细节，不遮住本次景别的关键部位（通常是脸和关键手势），不让大面积遮挡破坏角色辨识；手持、接触产生的必要局部遮挡可以保留；避免近景巨型电脑、横贯画面的桌板及占据中心的大物件。任务需要较大物件时优先侧置、后置或裁去非关键部分，保留该景别需要的角色辨识与动作信息；明确的手部等局部特写不强求脸部入画，不另设机械面积配额。

举例：两个人共同准备角色和拍摄物件；两个角色用不同的工作状态形成比较；人物俯身检查画面；手把步骤模块接起来。让表情和姿态来自任务处境，固定五官可通过身体、视线和道具表达。多人要有共同物件、交流或对照关系，不只是排在一起。

人物与必要物件可一起生成，保持相同透视、材质与接触关系，例如手抓住物件、脚接触支撑面；也可按已选景别在页边裁切非关键部分，保留本次任务所需的辨识与动作信息。支撑关系不等于必须画桌椅或地板。图片在画内结束时应有自然轮廓或合理遮挡，不留悬空桌板和硬切背景补丁。不要无缘由地生成舞台、高台或微缩地板。

## 输出素材

独立角色/道具/任务插画默认透明底，调用时启用实际透明输出能力；仅在提示词写“透明”并不保证文件透明。不支持时使用可用的去背景工具，保留原图，验证结果确有透明区域后再叠加到页面。不要只因文件是 PNG 就称透明。

去背景要保留属于任务的桌椅、道具和接触关系，不把所有环境物件一并剥掉。完整场景仅在联合构图需要时选择，并安排与页面自然衔接。纯色底、信息框、标题、数字和图表由 PPT 原生对象完成。

提示词用以下短骨架，按当前素材填写：

```text
用途：可编辑 PPT 的独立插画，不是整页幻灯片。
参考：图A负责身份，图B负责画风（可同图）；锁定具体标志、比例和媒介。
任务：谁在做什么，如何表达本页结论；只有必要时才指定互动人物或物件，单人动作也可成立。
构图：角色是插画第一视觉主体；填写景别、朝向、关键动作及图文关系，指定必要支撑和裁切位置。
主次：只保留任务必需的道具；无任务依据不生成书桌或办公室，前景/道具不压过角色，不遮挡本次景别必须保留的关键部位。
表现：沿用选定线条/材质与配色；可适当夸张角色姿态与表情，保持身份、比例和媒介；道具在尺度、对比与细节上从属。
输出：透明底（完整环境仅在明确选用时）；必要部位完整，不绘制文案、数据或界面文字。
```

只生成当前制作范围所需素材。生成后直接展示并继续排版，不逐图等待、不主动检查画面或自动重绘。可检查文件、尺寸和透明度；页面布局检查只调整原生排版。用户要求改图时再按其指定范围修改；未经用户确认的图不标为已批准。用户素材留在执行项目，不写入通用 Skill。
