# 交付协议

## 选择输出

默认直接创建飞书原生幻灯片；只有用户明确要求本地 PPTX 时才启用对应路径。按 [工具适配](tool-adapters.md) 选择当前环境可用的工具。文字、数字、胶囊、框线和图表用原生对象，角色和截图独立成层；不把整页生成图当作可编辑稿。图片可移动、缩放、替换，不代表五官肢体或截图里的按钮是原生对象。

新稿先按主流程确认逐页大纲、角色母图及制作安排。长稿、新角色或新风格默认先交付3–5张有代表性的可编辑样稿，取得整体视觉确认后再完成剩余稿件；已认可风格的短稿、局部修改或用户明确跳过样稿时直接制作。用户只要样页时完成该范围，不额外生成整套。样稿及后续整套沿用同一飞书稿，复用已认可页面并恢复原大纲顺序，可附总览。沿用既有稿的链接或项目路径，除非用户要独立新稿；不要为修一页复制出整套新链接。修改前读取云端最新版并留快照，优先替换受影响对象；用户手动修改成为当前基准，不能重跑旧脚本覆盖。回读比较请求范围外的文字、几何、样式及页序，微小数值归一化允许明确容差。

## 飞书原生路径

优先使用已连接的飞书幻灯片能力；也可通过已安装并授权的 `lark-cli`，它不是某个 agent 的专属工具。有配套飞书 Skill/文档时读取当前协议；没有时先读本机 help/schema，不能猜 XML/API。

原稿整理 → 大纲/角色/制作安排确认 → 联合构图 → 按本轮范围生图与原生排版 → 检查、写入、回读与截图。需样稿时：先交付代表页并等待整体视觉确认，通过后复用样稿、补齐其余页再交付；直接制作分支则完成约定范围后交付。大纲确认前不创建或写入云端稿件，样稿确认前不批量生成剩余素材；全程不逐张素材等待批准。CLI 调用显式指定 `--as user`，正文通过结构化参数或文件传入，不拼接进 shell。先确认本机批量页数限制：超限时在同一演示稿逐页追加，记录已创建页、版本与素材映射；部分失败先回读恢复，避免重建重复稿。

本地图片先按工具当前规则上传；只有明确支持本地路径占位符的命令才使用占位符，不能把它套到原始 API。图片显示框保持与已裁切图相同的比例，避免目标平台再次裁掉证据。回读核对页数、页序、文字和图片，并按样机协议把最终图片对象映射回 evidence_images，确认屏幕层和外框层确实都在稿内，或使用了完整合成图；同步检查palette_contract.roles.primary是否保留主题识别、重点标题/强调是否沿用主色或中性反白；背景与角色有清楚分离，新增色系须有secondary_colors依据。回读时在每页native_colors中汇总实际原生背景、文字、形状填充/描边及渐变停靠点颜色（转成#RRGGBB，排除完全透明项与图片像素），由审校器核对是否超出声明色板；未取得实际颜色不能报配色审校通过。字段校验之外仍看页面里的颜色角色与面积，不能因字段完整放过黄色主标题或橙色大底抢走蓝色主题。HTML/XML 的空白折叠可归一化比较，不以此掩盖丢字或断行变化。

## 本地 PPTX（用户明确要求时）

使用当前环境可用、能创建独立文字/形状/图片的 PPTX 库或应用 API。字体组合按用户参考优先；具体引擎的坐标与字号单位不能互相混用。保存可再次编辑的源文件与素材，导出后用可用的读取器和渲染器检查包结构、页数、原生对象、换行和遮挡。

Codex 可使用其 presentations/Artifact Tool 路径；其他 agent 使用自身的原生 PPTX 工具，不要求安装 Codex 的私有运行时。无法执行某项检查时明确指出验证边界，不能只生成文件就宣称在目标应用里测试过。

## 出血、编辑与验证边界

有意出血记录在 bleed_objects：logical_bbox 是完整构图位置，visible_bbox 是与画布的交集，edges 是裁切边，crop_reason 解释目的，protected_regions 是须在画内保留的关键区域。正文不可意外越界。平台不支持画外对象时，用裁切图像、原生裁切路径或遮罩输出等效画面，并保留原素材和参数；不能关闭全部越界检查放行。

用户的字体、留白和参考构图优先于工具通用的单字体或密集卡片默认。写入前与回读后分别检查封面是大字主导、对齐适合内容与角色关系、辅助角色实际出现且通过动作参与内容，任何含生成图的页面还要用最终生成图片对象的画内可见区域并集核对至少占整页1/3，透明留白、画外部分、原生底色和真实截图不凑数；多页样稿的构图/背景角色应有实质变化；不能以工具要求封面大图或统一底色为由恢复左文右图、全白近白。局部修改只检查受影响范围，不为补节奏改动用户未请求的既有页。只修受影响的原生排版，不因布局检查主动重绘已生成角色。截图里的播放控件是静态图时直接说明，不能暗示可点击播放。

PPTX 导入飞书是另一条验证路径；本地稿不能冒充飞书原生稿，创建并回读不能冒充实际手动编辑。目标端字体/回退、换行、层次和裁切以实际截图为准；同时查看生成场景与页底是否有硬切缝、底色断带、悬空桌板/物件或不应出现的高台。边缘问题优先按原计划调整出血、遮挡和原生排版；不能暗中重绘角色。无法在现有素材上解决时说明缺口，由用户决定素材修改。不提前承诺无损。几何检查通过不代表用户认可美术。

用户只研究或优化 Skill 时不为测试写入账号；用户明确要求制作稿件时才按授权写入。公开分享、权限变化、删除和覆盖重要资料另按授权处理。缺少工具时保留已有产物并解释缺口，不退化成整页图片冒充原生交付。
