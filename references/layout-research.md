# 排版约束的依据与边界

检索与参考图复核日期：2026-11-02。执行数值只维护在[排版基准](layout-rules.md)，本文件解释取舍，不另建第二份数值规范。

## 一手来源支持什么

| 来源 | 核实内容 | 采用范围 |
|---|---|---|
| [IBM Design Language — 2x Grid](https://www.ibm.com/design/language/2x-grid/) | 用网格、边距、栏沟和基础单位建立稳定空间关系；在有边距时划分有效内容区 | 采用统一版心、栏沟和间距系统的思路；IBM 自有网格不等于本 Skill 的具体列数或 PPT 安全区标准 |
| [NN/g — Proximity Principle](https://www.nngroup.com/articles/gestalt-proximity/) | 靠近的元素更易被理解为一组，分开的元素更易被理解为不相关 | 采用组内近、组间远；具体倍数由本 Skill 选定，不冒充研究结论 |
| [Microsoft — Guides for arranging things on a slide](https://support.microsoft.com/en-us/powerpoint/training/guides-for-arranging-things-on-a-slide) | 支持边缘/中心对齐、水平/垂直等距分布和辅助线 | 落实显式锚点与同级对齐；工具功能本身不保证画面好看 |
| [Duarte — 7 ways to make your best PowerPoint presentations](https://www.duarte.com/blog/7-ways-to-make-your-best-powerpoint-presentations/) | 每页围绕一个想法，并为每页建立标题 | 沿用主文件的单页核心观点，不重复增加一份叙事规则 |
| [Duarte — Display data in presentations](https://www.duarte.com/blog/display-data-in-presentations/) | 讲演和传阅资料的密度需求不同；资料仍需留白、标题与视觉层级 | 区分讲演页和资料页，不能因装不下而默认转成密集资料页 |

这些来源没有为本 Skill 提供统一留白比例、最大内容块数、固定边距或误差容限的实验证据。本次选定的数值是可修改的制作默认值；置信度在原则上高，在具体阈值上中等，需以真实样稿迭代。没有采用“7±2 推导页面块数”“所有页必须 40% 留白”“把视频安全框直接当 PPT 标准”等跨场景结论。

|---|---|---|
| 1 蓝白 Jadara | 标题/内容有共享左线，价值页是多组图标文字加右侧大人物；线框与人物互动 | 保留共享锚点与破框；六项价值不能伪称符合新块数上限，讲演时需筛选或拆页 |
| 2 蓝黑商业 | 多数普通页标题位置稳定；团队页三组、流程页四节点；视觉尺度随页型变化 | 采用同页型固定标题线、三栏和四项排列，允许封面独立 |

| 7 浅紫学术 | 页眉/注释带稳定，正文列规整，人物或放大镜跨色面 | 页脚有内容才预留；资料页和场景页分别处理密度 |
| 8 蓝白心理健康 | 三项内容、竖向数字组、巨幅半身/手部及页边曲线 | 允许大视觉和不同页型；不能按图片框面积强求统一留白比例 |
| 9 简历 | 左侧大像素脸，中部介绍/教育，右侧技能/经历；存在四个可单独命名的文字区 | 分块按阅读任务计数，不按软件分组计数；整体属于阅读型参考，不强行压成讲演样式 |
