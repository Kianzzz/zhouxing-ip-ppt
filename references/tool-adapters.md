# 工具适配

只在接入工具、缺少能力或准备依赖时读取。设计原则见主入口，工具文档只负责调用、格式和授权，不把其通用模板当作本次版式。

## 安装与已有工具

完整安装本目录，检查入口、默认母图、主题与设备资源可读；已有同名 Skill 更新前留可恢复备份。安装不等于制作，不默认创建云端试稿、运行全部诊断或准备本地 PPTX 引擎。

已有可创建独立文字/形状/图片、回读与预览的飞书工具就沿用，包括豆包原有工具、连接器或已授权的 lark-cli；不因工具名称不同重装一套。缺授权时只发起当前必要登录/权限步骤，并展示工具给出的链接；已有授权不重复申请。缺工具时按当前[官方 CLI 文档](https://github.com/larksuite/cli)接入；没有安装能力时说明具体缺口及平台连接入口。接口和参数以当前工具文档或本机 help/schema 为准。

飞书[网页入口](https://www.feishu.cn/)和[客户端下载](https://www.feishu.cn/download)不等于 agent 已有写入权限。用户无需在聊天中提供密码或密钥。只安装时简短报告状态；用户同时给出制作任务时，接着整理大纲与参考，按主流程确认。

## 按实际需要准备

| 能力 | 选择与边界 |
|---|---|
| 生图 | 能实际传入参考图片；独立素材优先使用真实透明输出参数，否则用可用去背景工具。没有能力时可复用匹配素材或说明缺口 |
| 原生排版 | 复用可编辑飞书能力；用户要 PPTX 或出现交付协议规定的字体保真需求时启用本地引擎，不退化成整页图 |
| 预览 | 优先目标端截图/渲染；几何回读不能冒充字体与视觉效果验证 |
| 字体 | 按 font-groups.json 准备本次所需字体面，核对目标端实际回退；字体不随 Skill 打包 |
| 设备外框 | 复用内置模板或等效合成能力，见样机协议；不重新下载/重画设备 |
| 布局排障 | 优先用已有测量能力；难定位时才准备诊断脚本依赖，不作为每页制作前置 |

本 Skill 的 Python 检查器只需标准库。Node 工具通过 `scripts/canvas_runtime.mjs` 查找 Skill 附近、当前执行项目的 `@napi-rs/canvas`，也支持已有依赖路径 `RUNTIME_NODE_MODULES`。仅实际调用 Node 工具且无等效能力时准备该依赖。素材/字体路径按执行项目解析，不复制其他 agent 的私有运行时、配置或账号。

安装成功、静态检查通过与实际制作效果分别报告；未实测的能力不称为已通过。
