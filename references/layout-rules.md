# 排版基准：边界、分块、对齐与留白

联合构图时必读。本文件是这些约束的唯一数值来源；字体、配色与角色语言见[视觉系统](design-system.md)，研究依据见[排版依据](layout-research.md)。以下数值是本 Skill 的工作默认值，不是行业标准，也不是从参考缩略图精确测出的结果。

## 适用范围与优先级

默认用于 16:9 中文讲演稿。优先级沿用主文件；本文件补足未指定项。已有稿只调整本次涉及的对象，不为套用新规则改写整稿。阅读型资料页须由用途决定，不能仅因内容装不下就切换为资料页。

“必须／最多”是默认执行约束；“目标区间”用于诊断，超出后检查原因，不以数值单独判定审美。只有本文件明确允许的页型/构图例外，或用户明确指定的偏离才可采用；不能用一句“构图需要”豁免任意约束。在已有页面记录中注明页码、偏离项和目的即可，不另建审批流程。例外不能掩盖漏字、遮挡、证据裁失或字体不可读。

## 1. 安全边界与坐标

所有数值以 960×540 逻辑画布为基准，不直接等于目标引擎的 px 或 pt。同为 16:9 时按画布宽度比例整体缩放；其他比例重新计算版心和分栏，不拉伸原稿。

| 项目 | 默认约束 |
|---|---|
| 左右安全边距 | 各 48，即各占页宽 5% |
| 上下安全边距 | 各 32，即各占页高约 5.9% |
| 安全版心 | x=48–912，y=32–508，宽 864、高 476 |
| 页脚（有才预留） | 放在 y=480–508；正文/主体与页脚至少隔 24，因此主体底边不超过 y=456。没有页脚时不空留此带 |

标题、正文、数字、图表标签、图注与页码的可见内容必须落在安全版心内，文字框也不能溢出画布。截图中的关键证据和本次景别需要保留的角色部位按同样边界保护；全身/半身通常保护脸与关键手势，明确选用手部等局部特写时不强求同时出现脸。背景色、装饰线和非关键人物肢体可以有意出血，按交付协议保留裁切依据；不把所有图片强行缩回版心。画内分栏边界可被插画跨越，但不能遮挡文字或证据。

## 2. 分块数量与计数口径

内容页默认 2–3 个一级内容块，最多 4 个；封面、过渡和收束页默认 1–2 个。标题区、统一页脚不计入内容块，但占用空间。所有块须共同回答本页的同一个问题，例如比较页的两个方案、解释页的多条证据；不是允许一页并列四个无关结论。单主体页可以只有 1 块，不为达到默认数量凑块。

“块”是可被单独命名、需要观众单独阅读的内容单元：一个论点及其说明、一张图表及紧贴的解释、一幅场景及对应说明。计数按观众的阅读任务，不按 PPT 对象数量或是否放进同一个外框：

- 一张卡内的标题、图标、数字、解释共同表达一个意思，计 1 块；三个独立卡片计 3 块。
- 双方案对比计 2 块；四个需要分别理解的流程节点计 4 块。六个带独立标题的要点不能套一个大框称作 1 块，应拆页或移至附录。
- 同一图表的坐标轴、图例、数据点不分别计块；并列且各有独立结论的图表分别计块。表格是一个数据展示单元，但仍须保证目标端可读，不能借此塞入全文。
- 指向某块的辅助角色归入该块；占据独立阅读区域的角色场景另计 1 块。背景和纯装饰不计块，也不能成为制造视觉噪声的借口。

资料页也遵守最多 4 块；用户明确要求一页保留完整目录、长流程或复杂图谱时，可保留超过上限的结构，记录用途并检查阅读尺寸，不自行删内容。

## 3. 统一网格、锚点与排列

安全版心内默认采用 12 列辅助网格：单列宽 50，列间距 24。跨 n 列的宽度为 50n+24(n−1)；下表宽度均基于此默认值。按间距条款调整栏沟 g 时，单列宽重算为 (864−11g)/12，跨列宽同步重算；不能只增加栏沟使内容越界。这不是要求把每个对象都做成独立卡片。文字与信息容器对齐列边，插画按任务和可见轮廓布置。

| 内容关系 | 默认排列 | 对齐依据 |
|---|---|---|
| 一个主体 | 通栏或一主一次 | 主体边缘与版心/列边对应；标题建立唯一首读 |
| 两项平级比较 | 6+6 列，各宽 420，中间隔 24 | 同级标题顶边一致，内容顶对齐；同类图表使用一致绘图区 |
| 主信息与辅助视觉 | 7+5 或 8+4 列，也可镜像 | 大区承载主要信息，辅助区与其标题或主体形成明确关系 |
| 三项平级内容 | 4+4+4 列，各宽 272，间隔 24 | 容器等宽；标题、图像区、说明区分别对齐 |
| 四项内容 | 默认 2×2 | 同行顶对齐、同列左对齐；每行按最高内容块确定行高 |
| 流程或因果链 | 单向横排或竖排 | 默认从左到右或从上到下；换行时用编号明确顺序，连接线不穿字 |

四项仅有短标签/数字时可横排；有段落说明则用 2×2 或拆页。默认中文正文左对齐，不用两端分散强撑宽度；短封面标题或数字可以居中。同一层级不随机混用左对齐与居中。并排同级组先按顶部对齐，不因文本长短分别垂直居中。

每套稿先确定正文左线 x=48、右线 x=912、普通内容页标题顶线 y=32，以及该页型的正文起始线。同页型按预计最长标题确定统一标题区高度，正文起始线在其底边之后预留下节规定的间隔；短标题不拉动正文上移。两行标题超出既定标题区时采用单独页型，不让正文每页随机上下漂移。封面和章节页可有独立锚点，不要求全套所有标题同高；不是所有人物都要和标题齐头。

容器、卡片和设备框按几何框对齐；文字检查实际字形边缘，透明插画检查可见主体。先做几何对齐，再允许不超过 4 的光学位移，并在同类对象中一致使用。几何对齐检查容差为 2；光学校正对象单独按可见边缘判断，不能用统一放大容差掩盖偏差。

## 4. 间距与排列细节

以 8 为基础间距单位，常用 8、16、24、32、48；列宽和字形尺寸不必是 8 的倍数。相同层级整套沿用选定值。

| 关系 | 默认值与约束 |
|---|---|
| 图标—标签、图—紧贴图注等紧密关系 | 8 |
| 小标题—其解释，组内条目 | 默认 16；紧凑时可选 8，同级统一 |
| 无边框独立组之间 | 默认 32；允许 24 或 48。沿同一轴比较时，至少为相邻组内最大条目间隔的 2 倍；不把行距或内边距算作条目间隔 |
| 并列栏/卡片之间 | 默认栏沟 24。有明确容器边界时不套上述倍数；无容器且组内间隔为 16 时，将栏沟统一调为 32，并重算列宽，不挤压组内文字 |
| 页面标题区—正文主体 | 默认 32，最小 24；从标题区实际底边测，不从文字框名义高度猜 |
| 卡片内边距 | 默认 24，最小 16；同组统一 |
| 正文段落行距 | 默认字号的 1.3–1.5 倍，按实际字体和目标端预览确定一档；不挤行距塞内容 |

间距沿阅读方向测相邻可见边界；有容器时卡片之间测外框、内边距测框到内容。独立分组用间距区分，只有间距不足以说明关系时才加边框/底色。元素在一栏中应共享左线或中心轴；不逐对象新增无意义的坐标线。

## 5. 留白：口径、目标与处理

留白是无须读取的空间，不限于白色。这里的比例特指“安全版心内的结构空余率”，不包括页外边距，不统计白色像素，也不等于生成图片占比。

估算方法：在安全版心内，为每段文字（整段含行间空隙）、每个完整图表/截图、每幅插画的可见主体画紧包围框；先裁取各框与安全版心的交集，再合并重叠区域，计算 `1 − 内容框并集面积 / 安全版心面积`。标题、页脚计入内容框；背景色、纯装饰底框不计入。图表/截图内部空白不另算；透明图片去掉外围透明边，包围框内部空洞不再扣除。此法是保守的结构估算，不是精确的视觉负空间测量。

| 页型 | 版心结构空余率目标 |
|---|---|
| 普通讲演内容页 | 20%–35% |
| 以标题/短句为主的封面、过渡、收束页 | 35%–55% |
| 已明确用于独立阅读的资料页 | 15%–25% |

草图阶段预留相应空间；预览时核对结构，只有需要量化审计时才测面积。未测量只能写“按目标预留/视觉检查”，不能报精确百分比或声称数值达标。

低于下限：先检查内容是否过多或分组过密，再精简非必要说明、重排或拆页，不缩字凑比例。高于上限：检查是否出现无功能空洞、主体过小或关联内容距离过远；可调整现有图文尺度与位置，不添加无关装饰填洞。

全幅场景、跨区大人物、完整截图主导页的包围框会高估内容占用，不套比例。注明这类页型，改查文字周围的可读空间、组间距、首读与受保护内容。明确服务于人物视线、突出结论或收束的非对称留白可以保留，并说明用途。不能为了达区间机械缩小人物；大字、深底或大量留白也不自动代表设计质量。

## 6. 执行与验收

在现有大纲中补充“页型、内容块数与排列、角色任务、例外（如有）”；页型对应既定锚点，只有偏离时才逐页写坐标。整套的安全区、间距档位和页型锚点只记录一次，不逐页复制；不强制新建 JSON。

排版后先检查边界、块数和对齐/间距，再缩略检查首读、分组和空洞，最后在目标端阅读尺寸检查文字、图表和证据。只改变原生布局，不由排版检查自动重绘插画。详细几何测量见[诊断工具](diagnostics.md)；脚本当前不自动检查本文件全部规则，不能把脚本通过称为整套排版验收通过。
