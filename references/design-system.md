# 视觉系统

制作时只需确定本套字体、配色与构图语言，随后沿用。参考图说明要达到的关系，不是用来推算精确字体或统一占比的源文件。

## 字体与阅读层级

从 `assets/font-groups.json` 选择一组：B 用思源宋体 Heavy 作主字体；C 用得意黑 Oblique 作主字体。两组的辅字体均为阿里巴巴普惠体 3.0 SemiBold，说明字体为 Light 300；以配置中的字体面和深浅底颜色为准。按角色与内容气质选择，用户指定优先，不按真人/卡通机械分类。整套只定义一次，不逐页解释。

标题先建立阅读入口，正文承担必要解释，图注和页码从属。960×540 可从封面短标题 72–140、内容标题 38–64、正文 18–24、次级标签 13–16 起步；这些是构图参考值，按真实字形、内容量和目标端效果调整。字号与坐标一起按引擎比例换算，不把本地 px 直接写成另一引擎的 pt。

长标题按语义断行，保持词组和标点完整；正文不做实验性拆字。需要更多空间时重组内容或拆页。标题设计可用尺度、字重、断行、错位或与插画穿插，不要求每页都有字效。主字体不等于全页加粗，说明字体不等于一律小号。

使用实际字体族/字体面名称；得意黑自带 Oblique，不额外合成加粗或倾斜。配置中的别名须与当前字体文件匹配。先核对截图字形、换行和细字可读性；必要时查导出 PDF 的字体清单确认实际字体及字重，写入名称、XML 回读和本机安装均不能证明目标端已使用。缺字体时说明具体替换，不把同类替代称为指定字体。用户要求保留指定字体时，按交付协议提供可验证的本地文件；普通允许替代的稿保留主/辅/说明分工。Light 小字不清楚时先改善背景、字号与行距，仍不足才局部用 Regular 400。

## 配色与整套一致性

用户配色和指定参考优先；无指定参考时结合角色与内容选色，均无输入时用内置蓝系候选。先确定主色、页面背景、文字和少量强调，角色与真实截图保留原色。学习参考中颜色的用途、面积和对比，不能仅抽取衣服颜色铺满背景。

背景衬托主体，主色保持识别。沿用参考中有依据的辅色，不为让蓝色角色突出自动增加黄字或橙色大底。深底用清楚的浅字，浅底用清楚的深字。允许整套同底；有叙事需要时再变化明暗或色面，不为完成背景数量而换色。

## 内容决定构图

封面按下节联合构图，不固定左右各半；内容页按关系选择构图：

| 要表达的关系 | 可采用的组织方式 |
|---|---|
| 比较两种选择 | 对等场景及相应说明，人物行为直接表现差异 |
| 准备多个要素 | 横向任务场景，下方对齐角色、场景、道具等信息 |
| 讲步骤或方法 | 原生流程/数字，插画在需要处示范或指认 |
| 展示操作或结果 | 真实截图占主要阅读区域，标签贴近具体证据 |
| 提出观点或收束 | 大句子建立重点，插画与关键词或结果联系 |

这些是选择方法，不是整套配额。侧排与半身可以复用；桌面是否适用按角色任务判断，不作为默认构图。通过信息关系、主次尺度、景别和留白形成节奏；插画可以主导，也可以从属，无作用时内容页可省去人物。不用单一面积阈值替代构图判断。

## 封面：白底轻场景与标题组

无用户指定的背景/品牌约束时，封面默认采用白色底、少量场景线索、中近景或更近的大角色。保留角色原媒介和身份；表情、视线或动作引导主题。白色指文字留白区和环境底色，不是把角色、浅色地形或必要阴影一起漂白。画面丰富度服从主题，完整浓场景或透明角色单独排版仍可在用户指定或内容确有需要时采用，不把默认值扩展为所有正文页的模板。

先确定标题长度、断行和文字组位置，再生成一张角色与轻场景一体的无字底图。只保留能交代地点/气氛的少量轮廓；靠近文字时细节、对比与饱和度自然降低，延伸为同一空间的白色留白。避免两半硬拼、明显白雾带、矩形背景补丁或密集前景；过渡不能洗淡角色轮廓与五官。优先在生成时安排过渡，后期遮罩仅作小幅可读性修正。

主标题、紧随的副标题和必要署名使用原生文字。按语义组织标题行数，主副标题形成一个阅读组，先检查实际字形边界再定间距；不因固定坐标造成标题挤行或副标题远离。角色可以用手势、视线及非关键轮廓跨区连接文字，但不能遮字。按角色朝向与标题长度选择左文右图、镜像或上下构图，不为四个角色机械复制坐标，也不为了变化强行改变已适用的布局。

文字颜色按其背后的局部区域选择，白底优先深色标题与清楚的说明色，检查完整字形覆盖范围。若背景细节干扰，先简化或调整文字位置，再考虑局部遮罩；不能仅凭整图主色判定对比足够。标题、说明和数据不生成进底图。安全区、分块与场景出血例外沿用排版基准。

## 插画与空间关系

角色必须正在做与主题有关的事，趣味来自角色的表情、动作和人物关系；允许服务于内容的适度夸张。插画内部的角色主次、场景选择和道具限制统一按[角色与场景](character-workflow.md)执行。默认黑白线条和有限平涂的编辑插画不混入无依据的写实灯光与材质；用户角色保留其原媒介。

图片按可见主体定位，透明边距不代表人物体量。手、脚、家具要有可信接触与支撑，或通过合理遮挡/页边出血收尾；不把图片硬切在画内留下悬空横条。无需为了支撑额外生成舞台、台座或孤岛式地板。封面轻场景按上节执行，其他完整环境仅在内容与构图确有需要时使用。

分块计数、安全边界、对齐基准、间距和留白统一按[排版基准](layout-rules.md)执行；这里不另设阈值。插画任务与信息分组共同决定页面结构，不逐对象发明装饰。

实际页面先缩略检查重心与整套节奏，再按阅读尺寸检查字体、换行、截图和图文关系。对生成画面的审美与身份由用户确认，不自动重绘。难定位的几何问题才读诊断工具。
